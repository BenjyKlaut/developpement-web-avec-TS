# TaskMaster Pro

Application de gestion de tâches fullstack construite avec TypeScript, React et Node.js.

## Structure du projet

- `semaine-01-typescript/` : Fondations TypeScript & logique métier
- `semaine-02-react/` : Interface utilisateur (React + Vite + TS)

## Stack technique

- TypeScript
- React (Vite)
- Node.js (à venir)

## Installation

```bash
cd semaine-02-react
npm install
npm run dev
